# 奶蛙改图的修改边界与表情迁移

- 触发与影响：将已有图片的主体奶蛙化，同时要求保留外形、动作或表情时，笼统的角色替换指令容易扩大改动范围。
- 观察证据：本次多轮生成出现主体轮廓改变；一轮将原有张嘴表情统一为闭嘴微笑，后续恢复张嘴后仍有非目标表情变化。用户明确要求将保留与取舍整理为通用能力，不带入单张图片的具体元素。
- 分析：技能原有“小弧线嘴”和按奶娃结构调整动作的措辞，没有清楚区分平静基准与表情转换、整体替换与保留外形改造。这是已发现的指令缺口，不能据此认定它是生成偏差的唯一原因。
- 处理：明确修改边界与参考图职责，按各主体转换表情；用户指定的保留要求优先，不能兼容时说明冲突；按修改及保留清单检查目标与非目标区域。
- 验证与遗留：已检查技能规则、提示词骨架及本地参考路径的一致性；本次规则更新后未重新生图，实际改善程度待后续使用验证。生成模型仍不能保证像素级保留。
