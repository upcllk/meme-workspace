# 多人油画主体替换的人物对应偏差

- 场景：将多人古典油画中的人物替换成奶蛙，画面存在局部遮挡、搭肩和儿童等复杂关系。
- 现象与证据：用户对照原画和生成图右侧局部，指出人物对不上；生成图中该组人物和接触关系发生重组，出现难以与原画一一对应的小角色。局部遮挡使个别肢体归属不能完全确定。
- 分析：原提示词只笼统要求保留位置、姿态和互动，没有逐人建立对应关系，也没有专门核对遮挡和肢体归属。这是可改进的提示与检查缺口；无法据此断定生成模型偏差的唯一原因。
- 处理：奶蛙技能增加多人场景逐区清点、对应关系描述和结果核对；复杂场景可考虑分区域编辑，并核验拼接边界。
- 验证与遗留：已用本例检查技能流程覆盖人物数量、位置、遮挡及接触关系；尚未重新生成，实际改善程度待后续图片验证。生成工具不保证精确对应或像素级局部锁定。
