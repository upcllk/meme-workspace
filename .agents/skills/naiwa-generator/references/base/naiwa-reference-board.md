# 奶娃三视图基准

- 对应图片：`naiwa-reference-board.png`；由用户提供的三视图经透明背景处理得到。
- 用途：同一个奶娃角色的身份与角度基准，按任务选择对应视角；图中从左至右分别是正面、侧面和背面。
- 身份特征：黄色柔软的梨形身体、浅色椭圆肚皮、绿色圆眼睛、小嘴、长手臂、深色手脚和圆润轮廓。造型和动作可按任务调整，保持角色可辨认。
- 面部标志：以图中绿色圆眼、黑色瞳孔及简洁的小弧线嘴为平静状态基准，保持位置和相对比例；不因换装、主体替换或画风迁移改成其他角色的五官。用户明确要求大笑等表情时可按对应表情参考改变眼嘴状态，保持角色可辨认。
- 默认生成单个奶娃，不复制三视图布局或图片中的视角文字；用户明确要求时以用户要求为准。
