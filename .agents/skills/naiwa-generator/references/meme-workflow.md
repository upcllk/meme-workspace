# 奶娃表情包创作流程

本指南用于单张聊天反应图和一组静态表情包。用户要求视频或 GIF 动作时，改用本 Skill 的视频关键帧流程；静态姿势不能代替动作时序。

## 先拆解表情包语义

每张图围绕一个清晰反应设计，并按需要记录：

- 语义或配文：这张图要表达什么；没有指定文字时不擅自加字。
- 面部：眼睑开合、瞳孔方向、嘴型和嘴角；需要时允许两眼不对称。
- 姿势：头部倾斜、躯干方向、手势、脚步和重心，以及手与道具的接触关系。
- 镜头：正面、四分之三、侧面或俯仰角；近景或全身；主体在画面中的大小和留白。
- 背景与风格：透明贴纸、场景图或用户提供的原图画风。

不要只用“生气”“无语”等情绪词代替可见特征。用少量具体眼口和姿势特征让情绪容易辨认。用户明确要一套但没指定数量时，可提议 6 个反应；用户已列出表情时优先按其清单设计，不为凑数增加内容。用户只要单张时仍按单张处理。

可从以下视觉映射起步，再按角色特点和用户语境调整：

| 反应意图 | 面部线索 | 姿势线索 |
| --- | --- | --- |
| 无语 | 半眯眼、视线偏向一侧、嘴角平或略向下 | 轻微歪头、手臂放松 |
| 疑惑 | 视线偏上或两眼开合略有差异、小圆嘴 | 托腮或一只手微抬 |
| 委屈 | 视线下垂、眼睑沉、嘴角下压；是否流泪按情境决定 | 肩膀内收、身体略缩 |
| 惊讶 | 眼睛睁大、视线聚焦、小幅张口 | 手停在半空或身体轻微后仰 |
| 绷住 | 半眯眼、嘴巴抿紧或压平 | 身体保持僵住，避免动作抢走表情 |
| 爆笑 | 眯眼或闭眼、大幅张口 | 捧腹或身体后仰，明确双脚落点与手的位置 |

## 按职责选参考图

1. **身份参考**：使用奶娃三视图或适合目标角度的单视角，确定黄色梨形身体、浅色肚皮、绿色圆眼、黑色瞳孔及整体材质。三视图只定义身份和身体结构，不是表情或动作图；不要把三视图布局画进结果。当前没有合适的四分之三身份视图时，先用现有基准并在提示词描述目标角度，不要伪称图库已有该视图。
2. **表情参考**：只借用眼睑、视线和嘴型等面部状态，保留奶娃的眼睛身份特征；不迁入参考角色的身体、配色、背景或水印。
3. **姿势参考**：只借用躯干、头部、四肢、重心和接触关系；不自动复制参考图的表情、服装或场景。
4. **原图或构图参考**：用户给出的表情包原图可提供主体位置、裁切、背景和文字布局；依照用户要求保留内容，不把其中角色五官当成奶娃身份基准。

按本张图选择最相关的少量参考，不把整个图库或多张相互矛盾的表情同时交给生成工具。现有图库若没有对应情绪，不要把大笑参考说成哭、惊讶等表情的直接依据；改用清楚的文字描述。只有生成效果确实依赖特定样图时才请用户补充。

## 身份与变化的边界

- 默认保留奶娃的黄色身体、浅色肚皮、绿色圆眼和黑色瞳孔。眼睛可以因情绪眯起、闭合或改变视线；嘴可以张开、下垂或歪斜。保持身份特征不等于固定眼口状态。
- 头部转动、俯仰和透视会改变五官在画面中的位置及可见数量。服从目标视角和遮挡，不为展示双眼而扭曲头部。
- “愤怒”“忧郁”“贤者”等主题默认只改变表情、动作和氛围，不自动把身体改色或改造型。用户明确要求模式变身时，再说明允许改变哪些颜色、材质或身体特征。
- 一张贴纸默认一个主体、一个主要表情和一个主要动作。用户要求多人、连续动作或复杂场景时，遵循对应的替换和视频流程。

## 生成与字幕

- 成套请求先给出每张图的主题、表情/姿势设计、参考图职责和完整提示词；一次确认整套方案后再逐张生成。每次生成一张独立表情包，除非用户明确要求拼图或表情表。
- 透明背景适合单独贴纸；用户要求场景或给了需保留的原图时，按原图和用户边界处理，不套用透明背景默认值。
- 用户提供精确中文配文时，优先把角色与文字分开制作，并在本地排版能力可用时后期叠字；不要把“提示词写了原文”当成文字准确的证据。若只能由图像模型画字，先说明可能出现字形偏差，生成后逐字核对。
- 不复制参考素材中的水印或未指定文字。不要覆盖用户已有文件；保存位置遵循用户要求。

## 结果检查

逐张检查奶娃身份、目标眼口状态、手势和道具关系、主体完整度、视角与裁切。把结果缩小到常见聊天显示尺寸再看一次：情绪是否仍然一眼可辨，关键手势和道具是否还看得清。透明背景按实际 alpha 检查；配文按用户给出的内容核对。提示词不能证明生成结果符合要求，发现偏差时具体指出，不宣称像素级保留。

未来扩充参考图库时，优先补一张干净的正面四分之三身份视图，以及少量中性角度的表情近景和全身动作图。每张只承担一种参考职责，并附来源、视角、表情或动作、可借用内容及禁止迁移内容的说明；不要把字幕拼图或整套混合风格图片当成身份图。
