# 奶娃角色生成

先构思主题和简洁特征，再结合奶娃基准图逐张生图。用户不用逐项填写服装和动作。

## 参考图库

参考图库位于本 Skill 的 `references/`；默认以 `references/base/naiwa-reference-board.png` 三视图为角色身份和角度基准，并读取同名说明。三视图展示同一角色的正面、侧面和背面，除非用户另有要求，生成时只画一个主体，不复制视角文字。每张图旁边的同名 Markdown 描述其用途与需要保留的特征。优先读取基准图说明，再按本次需求选择少量相关参考图并读取同名说明；不要默认发送整个图库。用户指定的参考图优先，明确每张图是角色基准、画风参考还是服装/动作参考。若基准图或必要的图片缺失，说明缺少什么并请用户提供。

## 生成流程

所有生成、换装、主体替换和微调都以基准图中的眼睛和嘴巴为标志性身份特征：保留绿色圆眼、黑色瞳孔及面部位置与相对比例，不直接套用其他角色的五官造型。简洁的小弧线嘴是平静状态基准，不是所有表情的固定嘴型。根据用户要求或改图中需要延续的原表情，使用奶娃的五官表达对应情绪与眼嘴状态；需要大笑或张嘴时，按相关表情参考调整，而非统一成闭嘴微笑。视角、光线和画风可以影响呈现方式，不应抹去身份特征。用户明确要求的五官变化优先，提示词写明取舍，生成后核对。

默认每张脸的双眼状态一致：同时睁开、眯起或闭上，避免一只睁眼、一只闭眼的眨眼表情。侧面视角或遮挡可能只露出一只眼睛，不要为凑双眼而改变视角；用户明确要求或需要延续的原图表情包含眨眼、双眼不同状态时，遵循相应要求。生成后检查可见双眼的状态。

1. 从用户输入确定数量、风格和要求。未指定数量时生成 1 张；未指定风格时自行选择一个有趣主题，不要求用户填写描述。用户只要求构思或预览提示词时，只展示方案。
2. 自行构思指定数量的角色，每个方案包含中文主题名与 1–2 个简洁、易辨认的服装或道具特征；多张方案应有明显区别。用户给出明确主题时遵循其要求。历史去重只依据用户指定或实际可见的已有作品，不假设历史图库完整。
3. 对每个方案组织完整生图提示词：以奶娃基准图及说明保持角色身份，把主题和特征用于换装；明确画风、背景和其他参考图的作用。普通角色图默认透明背景，保持所有前景主体不变且完整，边缘干净平滑；主体替换则按下方规则保留原图场景。用户有其他要求时遵循用户。不要让服装或道具遮挡基准图中的重要面部和身体特征，除非用户明确要求。
4. 生成前，先向用户展示每张图对应的主题、参考图用途和完整提示词，并等待用户明确确认。用户可在确认前修改主题或提示词；未确认前不得调用图像生成工具。收到确认后，使用当前环境提供的内置图像生成能力，按工具说明处理本地参考图，每个角色独立生成一张；无须用户配置第三方 API Key。需要透明背景时启用工具的透明背景选项，保留输出的 alpha 通道；若输出并非透明，明确说明，不称其为透明图。若内置能力不可用，说明情况，不自行切换到外部 API。展示结果，并根据用户反馈对指定图片继续微调。
5. 用户要求保存时遵照指定位置；面向当前项目的成品保存到项目目录，预览可直接展示。不要覆盖既有文件。新生成作品只有在用户要求收入参考图库时才添加为参考图并写同名说明。

## 角色参考图换装

用户提供人物或角色参考图时，先观察其发型、服装配色和代表性配饰，提炼适合奶娃的简洁造型，再将角色基准图和用户参考图分别标明用途交给生图工具。不要虚构看不清的细节；需要保持的奶娃特征以基准图和说明为准。

## 大笑表情参考

生成大笑表情图时，从 `references/expressions/` 按需要选择少量关键帧或 `laugh-face-` 面部特写并读取同名说明，与奶娃身份基准图一起作为生图输入；分别标明身份基准与表情、动作参考，不复制参考图上的水印。面部细节重要时优先选择合适的特写，需要身体姿态时选择完整帧；按要求选用不同表情和视角。用户指定其他动作或口腔细节时优先遵循用户要求。关键帧仅供静态表情与姿态参考，不能单凭它们推断完整动作时序或声音。

## 视频关键帧与动作提示

用户计划用关键帧生成视频时，先按时间梳理镜头、角色方向、表情、手的位置、双脚落点与重心，以及相邻帧间的动作；同时确认关键帧模式、可用时长和素材角色。人物、服装、比例、背景和视角须可衔接，镜头切换可明确写入，不假设文字时间一定精准生效。

关键帧的全身姿态可能影响视频插值，不能只检查表情。若角色需要停步大笑，应生成双脚自然分开、落地站稳且不交叉的笑脸帧，明确双手位置，并写明“走到位 → 双脚落地站稳 → 插兜或甩头 → 大笑 → 收笑 → 转身”；若用户希望边走边笑，则保留符合步态的姿势。检查相邻帧的脚部、手部和朝向是否支持所需过渡，避免拿交叉迈步帧表达静止大笑；对遮挡或画面外的脚部保持不确定，不补造已验证结论。

视频提示应区分静态帧和两帧之间的动作，具体描述步伐、镜头、头部和头发惯性、微表情及幅度约束；指定时长内安排可完成的动作。若使用首帧、中间帧、尾帧模式，按界面实际名称标注顺序；表情特写可作独立角色/表情参考时才单独加入，避免把背景不同的特写误放进连续场景帧。提示词与关键帧仅能提高可控性，结果仍须对照生成视频检查，不能将单次异常归因于唯一原因。

## 图片主体替换

用户要求改图时，先明确目标与修改边界：整体替换为奶娃身体、保留原主体外形只换配色与五官，或仅修改指定局部。按用户意图选择，不将局部改造扩大为整体替换；多个主体且目标不明确时，先询问范围。

分别说明参考图的职责：原图提供需要保留的构图、轮廓、动作、朝向、服装、遮挡与表情；角色基准图提供奶娃身份、配色与五官风格；表情参考只提供相应的五官变化，不将其动作或背景一并迁入。基准图的平静表情不覆盖原图需要延续的表情，也不复制三视图布局或文字。

整体替换时，默认保留原图画幅、构图、背景、非目标主体和可见文字，将姿势与适合的服装迁移到奶娃身上；只有用户未要求锁定相关动作或轮廓时，才结合奶娃身体结构调整。保留外形或局部改造时，锁定用户指定的外轮廓、比例、动作和结构，只在允许的区域内改色或修改五官，不因套用基准图而改变主体形状。

需要延续原表情时，逐个主体记录情绪、嘴部开合程度、嘴角方向和眼睛状态，再用奶娃的五官风格表达，不照搬原角色五官，也不统一成默认微笑。张嘴、大笑等变化按需要选择相关表情参考；表情参考不代替原主体的动作和轮廓约束。看不清的细节标为不确定，不补造。

在提示词中明确“允许修改”和“必须保留”的内容。用户明确要求优先于技能默认值；角色基准不能覆盖用户指定的轮廓、动作或表情。若要求之间无法兼容，先说明具体冲突并确认取舍，不默默牺牲某项要求。

默认让替换内容融入原图的画风：观察并在提示词中描述原图的笔触、材质、色彩、光线和边缘处理，并将这些特征应用于奶娃及其五官表面。例如绘画中的奶娃应呈现相应的绘画笔触，而非光滑的贴纸或塑料质感；不要把某一种绘画风格强加给所有原图。画风适配仍须保留奶娃的五官身份，并遵循本次约定的表情变化和修改边界。用户指定不同画风时遵循用户要求，尽量避免因此改动无关区域。

用户明确要求将多个对象或局部元素变成奶娃脸时，按要求处理多个目标，可只绘制脸而不添加身体，并尽量保留各目标的位置、大小与周围环境。

主体替换默认保留原图背景，不启用普通角色图的透明背景默认值，除非用户要求。生成后按约定边界核对：目标是否改到，轮廓、动作、表情和对应关系是否符合要求，非目标区域是否被误改。生成结果可能重绘未替换区域，不承诺轮廓、文字或其他细节像素级一致；如实报告观察到的偏差和无法确认的部分，不因提示词中写了保留就宣称已经保留。

## 多人场景替换

多人、互相遮挡或姿态复杂时，先按区域清点原图中要替换的人物，建立简短的对应清单：位置、前后层次、可见姿态或朝向、各自表情、服装或道具、需要锁定的轮廓或结构，以及与邻近人物的接触关系。局部被遮挡的人物也单独记录；看不清的人数、肢体归属或关系标为不确定，不补造。用户未明确指定目标且无法判断时询问；明确要求所有人物时按全部可辨认人物处理。

将对应清单和关键关系写入待确认的完整提示词，明确一人对应一只奶蛙，尽量维持人物数量、位置、相对大小、朝向、前后遮挡、手臂归属和接触关系，不凭空增加、合并或遗漏角色。场景复杂时优先描述容易混淆的局部，例如“后方人物的手臂搭在右侧人物肩上”，同时保留原图的服装、道具和背景；不要求画出清单编号。用户确认后，以原图为构图参考、基准图为角色参考生成。

生成后按区域对照原图逐人核对数量和对应关系，特别检查遮挡人物、肢体归属、搭肩或拥抱等接触关系，区分可确认的错误与看不清的部分。若有明显偏差，向用户指出具体位置，不声称完全对应；根据用户反馈进行局部修正，修正时保持其他区域及画风。提示词和核对只能提高可控性，不能保证生成模型精确遵循；必要时建议分区域编辑并核验拼接边界，且不承诺工具支持像素级局部锁定。

## 提示词骨架

策划时：

> 请为奶娃设计指定数量的角色，遵循用户的风格偏好；未指定风格时自行选择主题。每个角色给出主题和 1–2 个简洁、容易辨认的服装或道具特征。多个角色应有明显区别，保留奶娃重要的身体和面部特征。

普通角色生成时，根据实际参考图与用户意图填充：

> 请以奶娃基准图为角色基准，设计【主题】造型，添加【特征】。保持基准图及其说明中要求的身体、颜色、面部和轮廓。明确其他参考图的用途。默认背景透明，保持所有前景主体不变且完整，边缘干净平滑；角色清晰、配饰简洁。结合用户的额外要求。

改图时，根据本次修改边界填充：

> 以【原图】为编辑底图，对【目标与范围】执行【整体替换／保留外形改色换脸／局部修改】。允许修改【内容】，必须保留【轮廓、动作、表情及其他约束】。以【身份参考】确定奶娃配色与五官风格，以【表情参考，如需要】表达各主体对应的情绪和眼嘴状态；不带入参考图中未指定的身体、动作或背景。保持【非目标区域】及原图画风。按上述修改与保留清单检查结果。
