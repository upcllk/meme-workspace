# 小猪角色生成

先构思主题和简洁特征，再结合小猪基准图逐张生成。用户不用逐项填写服装和道具。

## 参考图库

图库位于本 Skill 目录下的 `references/`；基准图及说明文件为 `references/base/pig-base.png` 和 `references/base/pig-base.md`。`base/` 存角色基准图，`styles/` 存画风参考，`examples/` 存造型案例。每张图旁边的同名 Markdown 描述其用途和需要保留的特征。优先读取基准图说明，再按本次需求选择少量相关参考图并读取同名说明，不要默认发送整个图库。用户指定的参考图优先，明确每张图是角色基准、画风参考还是服装或动作参考。若基准图或必要的图片缺失，说明缺少什么并请用户提供。

## 策划、确认与生成

1. 从用户输入确定数量、风格和要求。未指定数量时生成 1 张；未指定风格时自行构思一个有趣主题，不要求用户填写描述。用户只要求构思或预览提示词时，只展示方案。
2. 自行构思指定数量的角色，每个方案包含中文主题名和 1–2 个简洁、易辨认的服装或道具特征；多张方案应有明显区别。遵循用户明确指定的主题。历史去重只依据用户指定或实际可见的已有作品，不假设历史图库完整。
3. 为每张图编写完整生图提示词，并列明使用的参考图及用途。默认保持基准图中的四足动物形态、姿态、浅肉色身体、黑色豆豆眼、粉色猪鼻和二维手绘画风；不画成双腿站立的人物。默认配饰简洁、脸部清晰、背景透明，保持所有前景主体不变且完整，边缘干净平滑；用户明确要求其他造型或背景时遵循用户。
4. **每次生图前先展示每张图的主题、参考图用途和完整提示词，等待用户明确确认。** 用户提出意见时，修改并展示更新后的方案，再等待确认；未确认不得调用生图工具。批量任务可一次展示整批方案，用户只确认部分方案时只生成已确认部分。用户要求微调重绘时，也先展示更新后的提示词并等待确认。
5. 确认后，使用当前环境提供的内置图像生成能力，按工具说明处理本地参考图，每个角色独立生成一张；无须配置第三方 API Key。需要透明背景时启用工具的透明背景选项，保留输出的 alpha 通道；若输出并非透明，明确说明，不称其为透明图。若内置能力不可用，说明情况，不自行切换到外部 API。展示结果并根据用户意见调整。
6. 用户要求保存时遵照指定位置；面向当前项目的成品保存到项目目录，预览可直接展示。不要覆盖既有文件。新生成作品只有在用户要求收入参考图库时才添加为参考图并写同名说明。

## 参考角色换装

用户提供人物或角色图时，先观察并提炼发型发色及头饰、服装配色及领口、一个标志性配饰，设计适合小猪的简洁装扮。可以使用假发套、小披肩和小饰品，但以角色图和用户要求为准，不虚构看不清的细节。把小猪基准图标为角色身份参考，把用户图片标为换装参考；在生图前展示提炼结果、参考图用途和完整提示词并等待确认。

## 提示词骨架

策划时：

> 请设计指定数量、视觉特征鲜明的小猪角色，遵循用户的风格偏好；未指定时自行选择主题。每个角色给出中文主题名和 1–2 个简洁明确的服装或道具特征。多个角色应有明显区别，并保持小猪基准形象。

生图时，根据实际参考图与用户要求填充：

> 请为基准图中的小猪设计【主题】造型，添加简洁的【特征】。保持基准图中的姿态、四足动物形态、浅肉色身体、黑色豆豆眼、粉色猪鼻和二维手绘画风，不画成双腿站立的人物。配饰不要遮挡小猪脸部，默认背景透明，保持所有前景主体不变且完整，边缘干净平滑。结合各参考图的用途和用户的额外要求。
